# Visual benchmark

The benchmark compares the public `zplrender.render()` API with a checked-in
Labelary PNG generated from the sanitized shipping-label fixture.

Run the offline comparison:

```bash
python benchmarks/compare.py
```

Regenerate the reference only after intentionally changing the fixture:

```bash
python benchmarks/generate_reference.py
```

Reference generation sends the sanitized ZPL to the external Labelary API and
therefore requires network access. Private or production ZPL must never be used
as benchmark input.

The sanitized seven-label ZIP fixture mirrors the original stored-raster
archive structure. Regenerate it through Labelary with:

```bash
python benchmarks/generate_shopee_archive.py
```

The resulting `tests/fixtures/archives/shopee_shipping_labels.zip` contains one
`thermal_zpl_shipping_label.txt` member with seven `~DG`/`^XG` labels and their
corresponding `^ID` cleanup formats.

Generate Labelary's PDF references for both fixtures with:

```bash
python benchmarks/generate_pdf_references.py
```

This writes `benchmarks/reference/shipping_label.pdf` and
`benchmarks/reference/shopee_shipping_labels.pdf`. The first has one 4-by-6-inch
page; the second has seven 4-by-6-inch pages. These PDFs are reference artifacts
for PDF-level inspection, while `shipping_label.png` remains the source for the
automated thresholded-pixel comparison.

Generate one PNG reference for each of the seven ZIP labels with:

```bash
python benchmarks/generate_archive_png_references.py
```

The files are written as
`benchmarks/reference/shopee_shipping_labels/page_01.png` through
`page_07.png`. They are generated by sending the complete archive ZPL and
selecting each printable label by its Labelary index.
